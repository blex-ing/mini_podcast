# mini_podcast v0.1.0 — Base de desarrollo

Primera release administrativa y de calidad del repositorio.

## Incluye
- Ramas de desarrollo y publicación basadas en el modelo Yachay Kichwa.
- Especificación de flujo Git, QA, versionado y arquitectura objetivo.
- CI Python con compilación de sintaxis y lint Ruff.
- Plantilla de Pull Requests, archivo de exclusiones Git y changelog.
- Automatización de limpieza segura de ramas fusionadas y publicación de tags/releases.

## Alcance
Esta versión establece la base técnica y de gobierno. **No** incorpora todavía un generador completo de podcasts ni una aplicación distribuible.

## Compatibilidad
El script Python legado se conserva sin cambios.
