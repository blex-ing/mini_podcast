# mini_podcast v0.2.0 — Primera interfaz web

## Incluye
- Interfaz responsive Mini Podcast Studio: inicio, formulario de URL y biblioteca de demostración.
- React, Vite y TypeScript estricto con separación dominio/servicios.
- Configuración Cloudflare Workers Static Assets mediante `wrangler.jsonc`, Preview y producción.
- Integración Supabase opcional para guardar borradores con políticas de seguridad RLS.
- CI Python y frontend: compilación TypeScript/Vite y ESLint.
- Instrucciones de despliegue Cloudflare Workers.

## Validación
- GitHub Actions de la feature correctos (Python y Web).
- El despliegue y QA visual en Cloudflare deben verificarse desde la cuenta Cloudflare; no están confirmados por esta release.

## Limitaciones
Esta es una versión **visual y de preparación de infraestructura**: aún no extrae automáticamente artículos ni genera audio. Sin Supabase no almacena borradores.
