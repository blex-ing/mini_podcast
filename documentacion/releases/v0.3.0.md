# Mini Podcast v0.3.0 — Visión modular y Roadmap

## Novedades
- Visión de producto y definición de MVP para un motor general reutilizable de podcasts, incluido el perfil editorial de **Un Capítulo con Jesús**.
- Arquitectura objetivo con frontend Cloudflare Workers, API, procesamiento Python por módulos, proveedores LLM/TTS desacoplados y persistencia/almacenamiento futuros.
- Página independiente `/#roadmap` integrada en la interfaz, responsive para móvil y escritorio.
- Catálogo versionado con 5 hitos y 12 features, pesos que suman 100 puntos y criterios de aceptación.
- Avance de desarrollo y de producción separado; estados dinámicos mediante PRs de GitHub (merge a `develop` y verificación de presencia del commit en `master`).
- Validación estructural del roadmap integrada en GitHub Actions.

## Estado de avance
En el plan inicial, 3 features históricas representan **20 puntos**. Esta nueva feature suma **5 puntos** tras integrarse. El alcance del roadmap constituye una medida ponderada del trabajo planificado, no una medición de coste, tiempo ni capacidad final de procesamiento real.

## Limitaciones
- Todavía no existen motor de guiones IA, TTS o generación de MP3.
- Las consultas a GitHub requieren disponibilidad de la API pública; en caso de fallo se mostrará el estado verificado de referencia y un aviso.
- El QA visual de Cloudflare debe comprobarse mediante despliegue real tras el merge.
